Entry for the [One Line, One Chill](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488) bounty on make.fun.

## What it does

`main.ts` writes a single sentence of horror — under 200 characters — to `/output/entry.txt`. The line is fixed and deterministic, so every run produces the same text:

> The dentist held up my X-ray and said the tooth wasn't mine — my name was carved into its root, in my own handwriting.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). No dependencies, no network, no input.
